# Release notes

The changelog records project changes. The version in `pyproject.toml` is the
source version; its presence does not imply that it has been published to PyPI.
See [GitHub releases](https://github.com/amal-khailtash/pysv-const-expr-parser/releases)
for created releases and [PyPI](https://pypi.org/project/pysv-const-expr-parser/)
for uploaded distributions.

Release Please maintains `CHANGELOG.md` through release PRs. See the
[development guide](development.md) for review, tagging, publication, and recovery.
